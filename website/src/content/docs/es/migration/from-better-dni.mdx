[better-dni](https://www.npmjs.com/package/better-dni) valida DNI y NIE, y los genera. Esta librería cubre lo mismo y añade el CIF y los NIF K/L/M, la normalización, el motivo de cada error y mensajes traducidos. La comparación de esta página es con better-dni 4.4.2.

## Equivalencia de funciones

| better-dni | nif-dni-nie-cif-validation | Notas |
| --- | --- | --- |
| `isValid(x)` | `isValidNaturalPersonNif(x)` | También acepta los NIF K/L/M y la forma antigua del NIE. `isValidNif(x)` acepta además un CIF |
| `isNIF(x)` | `isValidDni(x)` | También acepta los NIF K/L/M. `validate(x, { types: ["DNI"] })` para aceptar solo un DNI |
| `isNIE(x)` | `isValidNie(x)` | |
| `ctrlChar(x)` | `computeControlCharacter(x)` | Pasa el número sin su carácter de control |
| `randomNIF()`, `randomNIE()` | `generateDni()`, `generateNie()` | De `nif-dni-nie-cif-validation/generate`; `{ seed }` para valores fijos |
| `randomNIFWith(letter)`, `randomNIEWith(prefix, letter)` | Sin equivalente | Usa `generateNie({ prefix })`; la letra de control se deriva de los dígitos |
| `normalize(x)` | `normalize(x)` | Los validadores ya normalizan: no hace falta llamarla antes |

## Antes y después

Antes, con better-dni:

```js
import { ctrlChar, isNIE, isNIF, isValid, normalize } from "better-dni";

isValid("12345678Z");             // true
isNIF("12345678Z");               // true
isNIE("X1234567L");               // true
ctrlChar("12345678");             // "Z"
isValid(normalize("12345678-z")); // true: primero hay que normalizar
```

Después:

```ts
import {
  computeControlCharacter, isValidDni, isValidNaturalPersonNif, isValidNie,
} from "nif-dni-nie-cif-validation";

isValidNaturalPersonNif("12345678Z");  // true
isValidDni("12345678Z");               // true
isValidNie("X1234567L");               // true
computeControlCharacter("12345678");   // "Z"
isValidNaturalPersonNif("12345678-z"); // true: sin paso previo de normalización
```

Para generar números, antes:

```js
import { randomNIE, randomNIF } from "better-dni";

randomNIF(); // un DNI aleatorio
randomNIE(); // un NIE aleatorio
```

Después:

```ts
import { createGenerator, generateDni, generateNie } from "nif-dni-nie-cif-validation/generate";

generateDni();           // un DNI aleatorio
generateNie();           // un NIE aleatorio
generateDni({ seed: 1 }); // "62707394X": el mismo en cada ejecución
createGenerator(42).nie(); // "Y4482905N": una secuencia de valores con semilla
```

## Diferencias de comportamiento

**NIF K/L/M.** better-dni los rechaza. Son NIF de personas físicas (españoles sin DNI, personas extranjeras sin NIE), y esta librería los acepta en `isValidDni` e `isValidNaturalPersonNif` ([KLM-1](/nif-dni-nie-cif-validation/es/reference/official-sources/#klm-1)).

**La forma antigua del NIE.** better-dni rechaza los NIE de 10 caracteres, como `X01234567L`; siguen siendo válidos ([NIE-3](/nif-dni-nie-cif-validation/es/reference/official-sources/#nie-3)).

**Separadores.** better-dni acepta minúsculas, pero rechaza espacios, puntos y guiones salvo que antes llames a su `normalize()`. Aquí todos los validadores normalizan, y `normalize()` también quita los puntos y añade los ceros iniciales de un DNI corto.

```js
import { isValid, normalize } from "better-dni";

isValid("K1234567L");             // false
isValid("X01234567L");            // false
isValid(" 12345678Z");            // false
normalize(" 12.345.678-z ");      // "12.345.678Z": se mantienen los puntos
```

```ts
import { isValidNaturalPersonNif, normalize } from "nif-dni-nie-cif-validation";

isValidNaturalPersonNif("K1234567L");  // true
isValidNaturalPersonNif("X01234567L"); // true
isValidNaturalPersonNif(" 12345678Z"); // true
normalize(" 12.345.678-z ");           // "12345678Z"
```

**CIF.** better-dni no tiene validador de CIF. Usa `isValidCif()`, o `isValidNif()` para aceptar todos los tipos.

**El motivo.** better-dni responde sí o no. `validate()` también da el tipo, la forma canónica y, si el valor no es válido, el código de error, la regla de SPEC y un mensaje en cinco idiomas: consulta [Códigos de error y mensajes traducidos](/nif-dni-nie-cif-validation/es/guides/errors-and-languages/).

<Aside type="tip">
Antes de cambiar, ejecuta las dos librerías en paralelo sobre tus datos guardados: los valores en los que discrepan son casi siempre NIF K/L/M, NIE antiguos o valores con separadores.
</Aside>
