# yup

Yup schemas (`yNif`, `yDni`, `yCif`) from `nif-dni-nie-cif-validation/yup`: the normalized output and the localized error with its code and SPEC rule.

```sh
pnpm start   # prints the results and exits with an error if any is not the expected one
```

From the root of the repository, install first with `pnpm examples:install` (see [../README.md](../README.md)). In your own project: `npm install nif-dni-nie-cif-validation yup`.
