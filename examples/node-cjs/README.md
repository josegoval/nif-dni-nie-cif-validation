# node-cjs

Validate Spanish NIF, DNI, NIE and CIF numbers from a CommonJS Node.js script (`require`).

```sh
pnpm start   # prints a result and exits with an error if any value is not the expected one
```

From the root of the repository, install first with `pnpm examples:install` (see [../README.md](../README.md)). In your own project: `npm install nif-dni-nie-cif-validation`.
